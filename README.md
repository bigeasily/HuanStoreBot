# HuanStoreBot - 异环店长自动化刷星脚本

一个基于 Python 的《异环》1-1 关卡自动化刷星工具，支持图像识别 + 自动制作食物 + 自动进出关卡。

**当前版本**：v1.1  
**分辨率支持**：**1080p（1920×1080）主屏幕**

---

## ✨ 功能特点

- 自动进入 1-1 关卡（仅首次按 F 键，后续循环跳过）
- 实时识别顾客头顶食物（支持大小变化）
- 边识别边制作对应食物
- 自动退出关卡循环刷星
- 食物制作逻辑独立（易扩展）
- 包含坐标获取和模板截取工具
- **⌨️ F9 一键安全退出**（按下 F9 后等待当前轮结束，安全停止脚本）

---

## 📋 使用前提

1. **游戏分辨率**：必须设置为 **1920×1080（1080p）**
2. **显示模式**：全屏，窗口化未作测试
3. **游戏窗口**：必须在**主显示器**上运行，不能放在副屏
4. **运行权限**：脚本必须**以管理员身份运行**
5. python3.12开发

---

## 🚀 安装步骤

### 1. 克隆项目
```
git clone https://github.com/bigeasily/HuanStoreBot.git
cd HuanStoreBot
```

### 2. 安装依赖

Bash

```
pip install -r requirements.txt
```

## 📁 项目结构

text

```
HuanStoreBot/
├── main.py                 # 程序入口
├── bot.py                  # 核心逻辑
├── food_maker.py           # 食物制作逻辑
├── tools.py                # 辅助工具（坐标、截图）
├── templates/              # 食物模板图片（必须）
├── requirements.txt
├── start.bat               #管理员启动脚本
└── README.md
```

1. **管理员身份** 运行 start.bat
2. 选择 **3** 开始自动化
3. 输入循环次数（建议先输入 3~5 测试）
4. 脚本运行期间，随时按 **F9** 安全退出（等待当前轮完成后自动停止）

------

## ⌨️ 快捷键

| 按键 | 功能 |
|------|------|
| **F9** | 安全退出脚本（等待当前轮完成后停止，不会中断正在进行的操作） |

> **注意**：脚本运行期间请勿操作鼠标和键盘，仅使用 F9 退出。

## ⚠️ 注意事项

- 游戏必须运行在 **主显示器** 的 **1080p** 分辨率
- 运行脚本时不要移动游戏窗口
- 脚本运行期间请勿操作鼠标和键盘（使用 F9 退出即可）
- 如果识别率低，请降低 confidence 值（bot.py 中默认 0.48）
- **首次进入关卡会自动按 F 键**，后续循环跳过该步骤，无需手动干预

## 🔧 常见问题

**Q：点击无效 / 脚本在桌面点击正常但游戏内无效？**

 A：必须**以管理员身份**运行脚本。

**Q：F9 按了没反应？**

 A：确保已安装 keyboard 库（`pip install keyboard`），并以管理员身份运行。F9 不会立即中断，而是在当前轮次完成后安全退出。
